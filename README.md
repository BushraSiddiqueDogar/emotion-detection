# MindMed AI - Your Intelligent Mental Health Companion

A comprehensive web-based mental health application that provides real-time emotion detection, therapeutic games, AI-powered chat support, and personalized wellness tracking.

## 🌟 Features

### 1. Real-time Emotion Detection
- **Facial Expression Analysis**: Uses webcam to detect emotions through facial recognition
- **Voice Tone Analysis**: Analyzes voice patterns to determine emotional state
- **Text Sentiment Analysis**: Real-time sentiment analysis of typed text
- **Emotion Statistics**: Visual representation of emotional states with percentages

### 2. Interactive Dashboard
- **Emotion Timeline**: Track emotional patterns over time
- **Mood History**: View recent mood entries with timestamps
- **Personalized Recommendations**: AI-generated suggestions based on current emotional state
- **Real-time Mood Updates**: Automatic mood tracking and timeline updates

### 3. AI Mental Health Companion
- **Intelligent Chatbot**: Conversational AI that provides emotional support
- **Context-aware Responses**: Tailored responses based on detected emotions
- **Therapeutic Conversations**: Guided discussions for mental health support
- **24/7 Availability**: Always available for emotional support

### 4. Therapeutic Games & Activities
- **Breathing Exercises**: Guided breathing with visual cues and timing
- **Sliding Puzzle**: Cognitive enhancement game with move tracking
- **Art Therapy**: Digital drawing canvas with color selection
- **Memory Challenge**: Brain training game with scoring system
- **Mood Journal**: Daily mood tracking with written reflection

### 5. Achievement System
- **Progress Tracking**: Unlock achievements for consistent app usage
- **Motivation Rewards**: Gamified approach to mental health maintenance
- **Goal Setting**: Personal wellness milestones and tracking

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Webcam access (for facial emotion detection)
- Microphone access (for voice analysis)
- Internet connection

### Installation
1. Download the HTML file
2. Open in your preferred web browser
3. Allow camera and microphone permissions when prompted
4. Start using the application immediately

### No Installation Required
This is a single-file web application that runs entirely in your browser. No server setup, database configuration, or additional software installation needed.

## 📖 Usage Guide

### Emotion Detection Tab
1. **Camera Setup**: Click "Start Camera" to begin facial emotion detection
2. **Voice Analysis**: Click "Start Listening" for voice tone analysis
3. **Text Analysis**: Type in the text area for real-time sentiment analysis
4. **View Results**: Check emotion percentages in the statistics section

### Dashboard Tab
- Monitor your emotional timeline
- View recent mood entries
- Get personalized recommendations based on your current state

### AI Companion Tab
- Start a conversation with the AI companion
- Share your feelings and receive supportive responses
- Get therapeutic guidance and coping strategies

### Therapeutic Games Tab
- **Breathing Exercise**: Follow the animated circle for guided breathing
- **Sliding Puzzle**: Solve the number puzzle to improve focus
- **Art Therapy**: Express emotions through digital art
- **Memory Game**: Challenge your memory with symbol matching
- **Mood Journal**: Write daily reflections and track mood levels

### Achievements Tab
- View your progress and unlocked achievements
- Set new wellness goals
- Track your mental health journey

## 🎮 Game Controls

### Breathing Exercise
- Click "Start" to begin the breathing animation
- Follow the circle: inhale when it grows, exhale when it shrinks
- Track your rounds and session time

### Sliding Puzzle
- Click adjacent tiles to move them toward the empty space
- Solve the puzzle by arranging numbers 1-15 in order
- Track moves and completion time

### Art Therapy
- Select colors from the palette
- Click and drag to draw on the canvas
- Save your artwork as a PNG file
- Clear canvas to start fresh

### Memory Game
- Click cards to flip them over
- Match pairs of identical symbols
- Score points for each successful match
- Complete all pairs to win

### Mood Journal
- Use the slider to rate your mood (1-10)
- Write detailed entries about your feelings
- Save entries to build your personal history
- View past entries to track emotional patterns
